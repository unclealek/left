# Category placeholder photography

These are illustrative examples of venue categories, never images of a detected or
confirmed venue. The actual venue's photo always takes priority. No category is
selected without venue context; unknown places use the existing warm interior.

Retrieved on 2026-10-19 from the photographers' Pexels pages. Used under the
[Pexels license](https://www.pexels.com/license/). Each bundled JPEG is a 1200px-wide
Pexels rendition; there are no runtime stock-image downloads, tracking URLs or
additional providers in the app. Seven new files total approximately 1.3 MB.
